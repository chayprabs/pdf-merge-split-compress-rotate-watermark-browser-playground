# Security Policy

## Reporting a vulnerability

If you discover a security issue in Press, please report it responsibly:

**Email:** [hi@chaitanyaprabuddha.com](mailto:hi@chaitanyaprabuddha.com)

Please include:

- A description of the vulnerability
- Steps to reproduce
- Potential impact

Do not open public GitHub issues for security vulnerabilities.

## Scope

Press is a client-side static web application. PDF processing runs locally in the browser via WebAssembly. There is no server-side processing of user files.

## Response

We aim to acknowledge reports within 7 days and provide a fix or mitigation timeline when applicable.
